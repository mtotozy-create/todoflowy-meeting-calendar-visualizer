# Meeting Calendar Visualizer

TodoFlowy 可视化会议日历与甘特图插件 (`todoflowy/meeting-calendar-visualizer`)。

## 特性

- **三视图支持**：周视图 (Week View)、月视图 (Month View) 和甘特图视图 (Gantt View)
- **多维度数据接入**：基于 `plugin.meetings` 同时整合个人会议 (`personal`) 与团队会议 (`team`)
- **时长热力图**：4 级色阶自动计算日忙碌指数
- **重叠冲突高亮**：实时计算时间重叠，红色边框脉冲提示冲突
- **多色标签与多维筛选**：Scope / Status / Team / Tag 多重过滤
- ** Quiet Workbench 设计规范**：完全遵循 TodoFlowy 原生设计语言
